# M2: Indicators + scanner

Status: built on branch `claude/jeron-m2-indicators-scanner-9pqzfs`, awaiting review.

## Goal (spec section 11)
Indicators, universe filters, the technical score and the daily scan.
*Accept:* indicators match a reference within tolerance; the scan takes < 5 minutes.

## Scope
1. **Indicators** (`app/indicators.py`, pure Python, no database): SMA, EMA, RSI(14),
   MACD(12, 26, 9), ADX(14) with +DI/-DI, ATR(14) and ATR % of price, volume vs its
   20-day average, distance from the 52-week high, relative strength vs Nifty 500
   over 3 and 6 months, and swing pivots (support and resistance).
   Conventions match broker charts and TA-Lib: EMA seeded with a simple average,
   Wilder smoothing for RSI, ATR and ADX.
2. **Reference check:** every indicator TA-Lib also has (SMA, EMA, RSI, MACD, ATR,
   ADX, +DI, -DI) is compared with TA-Lib on a real NSE price series (RELIANCE, kept
   as a test fixture) and on random walks. TA-Lib is a test-only dependency.
3. **New daily NSE files** (same archive server as M1, same polite downloader):
   | File | Gives | Used for |
   |---|---|---|
   | `ind_close_all_DDMMYYYY.csv` | Every NSE index's OHLC close, incl. Nifty 500, Nifty 50, India VIX (from 2016) | Relative strength now; regime filter later |
   | `sec_list_DDMMYYYY.csv` | Each security's price band and GSM stage (from 2020) | GSM exclusion now; circuit modelling in M3 |
   | `ind_nifty500list.csv` | Today's Nifty 500 list and industries | Nifty 500 label and sector, recorded from the first day seen |
   | `EQUITY_L.csv` | Company names, listing dates | Display |
   | `symbolchange.csv` | Old symbol → new symbol, with date | Joining a renamed company's history |
4. **Universe** (rebuilt per scan date, using only data up to that date): EQ series
   on the day (excludes T2T series BE/BZ; SME series are never stored), traded that
   day (excludes suspended), 20-session median turnover ≥ ₹5 cr, close ≥ ₹20, not on
   GSM, not on ASM, at least 200 sessions of history. Each run records how many stocks
   each rule excluded.
5. **Technical score** `tech-v1`, 0–100, from the spec's list. Points are starting
   values, written down so M3's backtester can test and recalibrate them:
   | Component | Points |
   |---|---|
   | Close above 200-EMA | 15 |
   | 20-EMA above 50-EMA | 10 |
   | RSI(14) 50–70 (5 for 40–50 or 70–80) | 10 |
   | MACD above signal (5), MACD above zero (5) | 10 |
   | ADX(14) > 20 with +DI above -DI | 10 |
   | Up day on volume ≥ 1.5× the 20-day average | 10 |
   | Within 5% of the 52-week high (5 within 15%) | 10 |
   | ATR(14) between 1% and 6% of price | 5 |
   | 3-month relative strength vs Nifty 500, percentile in the universe | 7.5 |
   | 6-month relative strength vs Nifty 500, percentile in the universe | 7.5 |
   | Close above the latest confirmed swing high | 5 |
   Every result keeps each component's value and points, plus support, resistance,
   20-day average volume and median turnover for M4's sizing rules.
6. **Daily scan** (`python -m app.cli scan`, and the last step of `daily`): refuses to
   run, and records why, when the day's quality report is missing or FAILs, or the
   Nifty 500 close for the day is missing. Uses split- and bonus-adjusted prices.
   Re-running a day replaces that day's results.
7. **API and web:** `/scan/latest`, `/scan/runs`, `/scan/{date}`; a Scanner page with
   the run's status, the exclusions and the ranked stocks; the spot-check page gains
   MACD and ADX.

## Schema changes (one migration)
- `index_bars`: index name, date, OHLC close.
- `security_status`: per stock and day, series, price band and GSM stage (point in time).
- `surveillance_flags`: ASM (and any other list) with start and end dates.
- `symbol_changes`: old symbol, new symbol, date.
- `scan_runs`, `scan_results`.
- `index_memberships` gets a unique key so the daily Nifty 500 refresh is idempotent.

## Spec points I read one way (please confirm)
- "Nifty 500 + other NSE mainboard stocks passing ₹5 cr turnover and ₹20 price": I
  apply the turnover and price filters to Nifty 500 stocks too, and show Nifty 500
  membership as a label. An illiquid Nifty 500 stock fails the 1%-of-volume rule anyway.
- ASM lists are only published on www.nseindia.com, which this project's network rules
  block, and the archive has no copy. `python -m app.cli asm-import file.csv` loads a
  list saved from NSE's ASM page; the scanner shows when it was last loaded. GSM is
  automatic from `sec_list`.

## Known gaps
- Nifty 500 membership before the first download isn't available from NSE's archive,
  so history starts on the first day Jeron sees the list. The universe itself doesn't
  depend on it (it is rule-based from the bhavcopy, so it has no survivorship bias).
- No APScheduler yet: `daily` is run by hand or a Windows scheduled task (M5 adds the
  scheduler with the alerts).

## Tests
Reference tests against TA-Lib; unit tests for each indicator's edge cases, the
universe rules, every score component, file parsers and symbol-change stitching; a
database test running the scan end to end, including the refusals; a timing test on
synthetic data at full-universe size.

## Acceptance checks
- `uv run pytest -q tests/test_indicators_reference.py` passes (indicators within
  1e-6 of TA-Lib after warm-up).
- `python -m app.cli scan` on a full database finishes in under 5 minutes; the run's
  duration is stored and shown on the Scanner page.
