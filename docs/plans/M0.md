# M0: Foundations

Status: built on branch `claude/project-thread-004cqa`, awaiting review.

## Scope
- Repo layout: `backend/`, `web/`, `docs/`.
- Backend: FastAPI app with `/health`, settings from env, SQLAlchemy models, Alembic
  initial migration.
- Schema: `instruments`, `daily_bars` (raw, per source), `corporate_actions`,
  `index_memberships` (point-in-time), `data_quality_reports`, `users`.
- NSE trading calendar (weekends, holidays, special weekend sessions) from a CSV.
- `DataProvider` protocol + bar validation + in-memory provider for tests.
- Web: Next.js status page showing backend and database health.
- Docker Compose (Postgres, backend, web), `.env.example`.
- CI: backend lint/format/types/tests with Postgres, web lint/types/build, Compose
  smoke test.
- Docs: `CLAUDE.md`, `docs/spec.md`, decisions 0001–0002.

## Out of scope
Any real market data (M1), indicators (M2), UI beyond the status page.

## Acceptance checks
- `docker compose up --build` starts all three services; http://localhost:3000 shows
  backend "running" and database "connected".
- CI green on the pull request.

## Known gaps
- Holiday dates in `nse_holidays.csv` are marked unverified. Only 2025 is included;
  the calendar refuses other years rather than guessing. M1 checks past years against
  bhavcopy dates and adds verified 2026 holidays from the NSE circular.
